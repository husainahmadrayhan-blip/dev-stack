# 💪 FitLog — Workout Library

FitLog is a responsive workout library and daily workout planner built for the Programming Hero B14-A6 assignment.

## Technologies

- Next.js 14 App Router
- React
- Tailwind CSS
- Lucide React
- LocalStorage
- FitLog REST API compatible data structure

## Features

1. Responsive workout library with 12 exercises
2. Workout detail pages with specs and instructions
3. Today's Plan with a five-workout limit
4. Saved workouts
5. Live Plan and Saved navbar counters
6. Sort by Duration, Calories, or Rating
7. Mark workouts as Done and remove them
8. Toast notifications
9. LocalStorage persistence
10. Custom 404 page and loading state

## API

Primary:
https://api.abcz.workers.dev/api/fitlog

Alternative:
https://api.api-store.workers.dev/api/fitlog

The included dataset matches the assignment API schema and is available in `data/workouts.js`.
